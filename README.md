# Code Immersives NYC — Coursework Archive

This repository collects the project work, exercises, assessments, and experiments I worked on during my time studying at **Code Immersives in New York City**. It follows my progression from HTML, CSS, and JavaScript fundamentals to interactive browser applications, React, backend development, databases, and deployment exercises.

## Reconciliation of the original repositories

This coursework originally lived across many, many separate Git repositories, often with a separate repository for each assignment or project. That work was later **reconciled and consolidated into this single repository** so it could be browsed and maintained together.

The individual folders retain their assignment and project names, source files, and any included instructions, assets, and package manifests. Here, “reconciled” refers to bringing the scattered coursework together into one archive; it does not imply that every exercise was completed, modernized, or verified to run today. This README documents the consolidated collection.

## What the work covers

- **Web foundations:** semantic HTML, CSS selectors, the box model, Flexbox, Grid, responsive layouts, and recreating reference designs.
- **JavaScript:** variables, arithmetic, conditionals, loops, functions, arrays, objects, destructuring, asynchronous code, and problem solving.
- **Interactive applications:** DOM manipulation, events, forms, browser storage, games, audio, external libraries, API requests, and charting.
- **React:** components, props, state, hooks, routing, forms, shopping carts, context, and Redux practice.
- **Backend and full-stack development:** Node.js, Express, REST-style endpoints, MongoDB/Mongoose, validation, authentication, and frontend/backend integration.
- **Assessment and delivery:** Jest exercises, midterms, portfolio work, and AWS deployment coursework.

## Exploring and running the work

Each folder is an independent exercise or project. There is no shared root application or single command that runs the whole collection.

- **Static browser projects:** open the folder's `index.html`, or serve that folder with a local HTTP server if the exercise uses requests or requires an HTTP origin.
- **Node.js exercises:** inspect the source and run the appropriate file with Node.js. Some interactive scripts use packages such as `prompt-sync`; check the folder's dependency information first.
- **Projects with `package.json`:** install dependencies inside that project folder and use the scripts declared in its package manifest. React projects commonly provide `npm start`; Jest exercises commonly provide `npm test`.
- **Backend and full-stack projects:** check their source, configuration, and local instructions for database connections, environment variables, ports, and any separate client/server setup.

For example, to explore the introductory React project:

```sh
cd react-intro
npm install
npm start
```

These are historical coursework files with the dependencies and conventions used at the time. Setup requirements vary by folder, and external APIs or deployment references may need adjustment. Consolidating the repositories did not include a collection-wide dependency upgrade or runtime verification.
